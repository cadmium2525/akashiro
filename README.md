# ウルトラ赤白帽

赤白帽子で「ウルトラマン」をつくる、スマホ向けの three.js ゲーム。

## あそびかた

赤白帽子は白い布と赤い布の2枚を、外周（ふち）だけで縫い合わせた帽子です。
内側の赤い布を引っぱり出すと、白と赤が半分ずつの風船のようになり、縫い目からツバが飛び出します。
それをツバが上に来るように回して、下から頭にかぶせるとウルトラマンになります。

画面の左半分が左手、右半分が右手です。

| STEP | 操作 | 目標 |
| --- | --- | --- |
| 1 ひっぱる | 左右に外側へスワイプ | 内側の赤を引っぱり出して風船にする（はなすと少しもどる・左右のバランス） |
| 2 まわす | 上スワイプ／左スワイプ | ツバを真上に、白を左・赤を右に向ける |
| 3 ツバをととのえる | 左右から内側へスワイプ | ツバをピンととがらせ、かたむきを0に |
| 4 かぶせる | 上スワイプ | 小学生の頭に下からかぶせる |

各STEPには制限時間があります。「できた！」ボタンで早めに次へ進めます。
最後に点数に応じて小学生がポーズをとります。

- S（85点〜）: スペシウム光線
- A（65点〜）: シュワッチ
- B（40点〜）: えへへ…
- C: しょんぼり

## むずかしさ

`src/main.js` の `DIFFS` で調整できます。

| | 制限時間（秒）[ひっぱる/まわす/ツバ/かぶせる] | 判定のあまさ | 布がもどる速さ | ゆれ |
| --- | --- | --- | --- | --- |
| かんたん | 15 / 15 / 15 / 10 | 1.5 | 0.04 | なし |
| ふつう | 10 / 10 / 10 / 8 | 1.0 | 0.1 | 0.12 |
| むずかしい | 7 / 7 / 7 / 6 | 0.7 | 0.2 | 0.3 |

## 起動

ビルド不要の静的サイトです（three.js r170 を `vendor/` に同梱）。

```sh
python3 -m http.server 8000
# スマホから http://<PCのIP>:8000/ を開く
```

GitHub Pages などにそのまま置いても動きます。

## 構成

- `src/main.js` — ゲーム進行、入力、カメラ、教室、採点
- `src/hat.js` — 赤白帽子（2枚の布＋ツバ。パラメータで変形するメッシュ）
- `src/kid.js` — 小学生とポーズ
- `src/hands.js` — プレイヤーの手
- `src/audio.js` — WebAudio の効果音
